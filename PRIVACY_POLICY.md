# Privacy Policy

Effective date: 2026-09-01

Mute Button for WhatsApp Web does not collect, store, sell, share, or transmit personal data.

The extension runs only on WhatsApp Web and adds a local mute/unmute button. When the button is clicked, it asks the browser to mute or unmute the current tab using the browser's native tab mute API.

The extension does not read, store, transmit, or analyze:

- WhatsApp messages
- contacts
- media
- phone numbers
- clipboard content
- browsing history
- account information

The extension does not use remote servers, analytics, advertising, tracking, or third-party data processors.

If this policy changes, the extension listing and this file should be updated before publishing a new version.

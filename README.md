# Mute Button for WhatsApp Web

A lightweight browser extension that adds a mute/unmute button inside WhatsApp Web.

The extension uses the browser's native tab mute feature. It does not collect, store, transmit, or inspect messages, contacts, media, or clipboard content.

## Features

- Adds a mute/unmute button to WhatsApp Web.
- Uses native browser tab muting.
- Works with WhatsApp Web in Chromium-based browsers.
- Does not require an external service.

## Permissions

- `tabs`: required to read and change the muted state of the current WhatsApp Web tab.
- `*://web.whatsapp.com/*`: required to inject the mute button only on WhatsApp Web.
